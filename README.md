# Ételreceptek Nyersanyagokból

## Project Overview
The "Ételreceptek Nyersanyagokból" project is a web-based application that allows users to input raw ingredients and generate cooking recipes along with their technological descriptions. The application is designed to be intuitive and user-friendly, providing quick access to recipe ideas based on the available ingredients.

## Installation
To set up this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```
2. **Navigate into the project directory:**
   ```bash
   cd <project-directory>
   ```
3. **Open the `index.html` file in a web browser.**

## Usage
1. Open the `index.html` file in any modern web browser.
2. Enter a list of raw materials in the provided textarea, separated by commas (e.g., `csirke, rizs, paprika`).
3. Click the "Receptek generálása" button to generate recipes.
4. The generated recipes will be displayed below, showing the name, description, and technology for each recipe.

## Features
- **Recipe Generation:** Automatically generates recipes based on user-inputted raw materials.
- **User-friendly Interface:** Simple and clear design tailored for easy navigation.
- **Responsive Design:** The layout adjusts to different screen sizes providing an optimal experience on various devices.
  
## Dependencies
This project utilizes the following libraries and frameworks:
- Tailwind CSS: For styling the application.
- Font Awesome: For icons used in the user interface.

These dependencies are linked directly in the `index.html` file, so no additional installation is required.

## Project Structure
The project structure is straightforward, consisting mainly of the following files:
```
/project-directory
│
├── index.html      # Main HTML file containing the application code
```

The `index.html` file contains:
- HTML structure of the application.
- CSS styling using Tailwind CSS.
- A script embedded to handle recipe generation logic based on input.

## Conclusion
The Ételreceptek Nyersanyagokból project provides a simple yet effective platform for cooking enthusiasts to discover new recipes from the ingredients they already have at home. Explore and enjoy the culinary possibilities!
